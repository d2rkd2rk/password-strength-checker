# 🔒 PASSCHK - Password Strength & Safety Checker

أداة بسيطة وسريعة لفحص قوة كلمة السر والتحقق من أمانها مباشرة من السطر البرمجي (Terminal / Command Prompt) بدون الحاجة لتثبيت بايثون!

---

## 🚀 المميزات (Features)

- ⚡ **سريعة ومفردة:** تشتغل بملف تنفيذي واحد بدون أي Dependencies.
- 🛡️ **خصوصية كاملة:** الفحص بيتم محلياً على جهازك 100%.
- 💻 **متوافقة:** تدعم أنظمة **Windows** و **Linux**.

---

## 📥 التحميل والتشغيل (Downloads & Usage)

ادخل على صفحة الـ **[Releases](../../releases)** وحمّل النسخة المناسبة لنظام تشغيلك:

### 🪟 لمستخدمي Windows:
1. حمّل ملف `PASSCHK.exe`.
2. شغل الملف مباشرة (Double Click).

### 🐧 لمستخدمي Linux:
1. حمّل ملف `PASSCHK`.
2. افتح الترمينال واكتب الاوامر دول للتشغيل:

git clone https://github.com/username/password-strength-checker.git


cd password-strength-checker


chmod +x PASSCHK.py


./PASSCHK.py
